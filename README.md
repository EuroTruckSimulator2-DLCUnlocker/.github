# ❓ FAQ

## Does ETS2Unlocker work with cracked versions?
No. This tool is intended for official Steam copies of Euro Truck Simulator 2 only.

## Is ETS2Unlocker safe?
The tool modifies DLC configuration files only. Always download from trusted sources and scan files before use.

## Do I need to reinstall after every ETS2 update?
Usually yes. Major game updates may overwrite modified files.
